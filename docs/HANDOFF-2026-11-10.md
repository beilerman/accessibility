## 4. Rules that must not be broken

**Content (full text in `docs/DECISIONS.md`)**

- Never infer. If a source does not say it, the catalog does not say it. Unknown stays unknown, and a negative claim needs evidence too.
- Never say a place is "accessible" or "ADA compliant" in Threshold's own voice, and never give a score or a "works for you" verdict.
- Every note cites exactly one page. Split a note that draws on two.
- Note IDs (`<slug>.<domain>.<n>`) are permanent. Never renumber or reuse one. To change a note, keep its ID and append a `revised` history entry. To withdraw one, set `review_status: retired` and append a `retired` entry; never delete it.
- Firsthand reviews stay in their own section under the reviewer's name. Never invent a review, a visit or a reviewer.
- Do not name venue staff, children or companions, and do not publish anyone's medical details.
- AI images are labeled wherever they appear, show nothing at ground level (no entrances, steps or paths), and are generated from a text description only, never from a copyrighted photo. A real, freely licensed photo always replaces an AI image.
- Supporting quotes (`pipeline/evidence/quotes.json`) are editorial evidence and are never shown on the site.

## 5. How updates are done

Scripts are in `scripts/research/` and `pipeline/`. Run everything from the repository root.

**Rolling recheck (weekly, eight places)**

1. `python3 scripts/research/queue.py recheck 8` prints the eight places read longest ago, with every note and its ID.
2. For each note, find the verbatim passage on the live source page that supports it. Any research agent can do this; ask it for `{note_id: quote}` plus a list of notes the page no longer supports.
3. Check every quote by machine against a fresh fetch before trusting it. `scripts/research/verify.py` does this for the new-note format; for rechecks, match with `quote_text()` from `pipeline/check_sources.py` (normalize both sides, then test substring).
4. `python3 scripts/research/recheck.py spec.json [date]` records the confirmed notes (`{note_id: quote}`) and stores the quotes.
5. Reword or retire unsupported notes by hand in `src/data/places.json`: keep the ID, set `retrieved_at`, append a `revised` or `retired` history entry that says why.
6. Put the re-read URLs in a file, one per line, and run `python3 pipeline/check_sources.py --only urls.txt`. Commit the snapshot.

**Adding notes or places**

1. Build the brief with `python3 scripts/research/queue.py brief <slug>…` or find thin listings with `queue.py thin`.
2. A research agent returns JSON: `[{slug, facts: [{domain, text, url, quote}]}]`, and for new places also `address_quote` and `address_url`.
3. `python3 scripts/research/verify.py out.json` re-fetches each URL and checks each quote. Misses are usually whitespace or `&amp;`; check them by hand.
4. Write each note yourself in plain words from its verified quote.
5. Apply: `apply_depth.py spec.json [date]` with `{slug: [[domain, text, url, source_type, quote]]}`, or `add_places.py places.json [date]` with facts as `[domain, text, url, source_type, published_at, quote]`. Always include the quote.
6. `python3 pipeline/check_sources.py --new-only`, and commit the snapshot. A pipeline test fails CI if any source has no baseline.
7. For a new place, add its route to the list at the top of `e2e/accessibility.spec.ts` and update the category lists in `src/__tests__/venue-expansion.test.ts`.

`source_type` is one of `venue_official`, `operator_official`, `partner_official`, `public_agency`. A unit test fails if a `venue_official` note cites a domain other than the place's own website.

**Source monitor**

`.github/workflows/source-monitor.yml` runs `pipeline/check_sources.py` every Monday and opens or updates one issue. Findings mean:

| Finding | Meaning | Action |
|---|---|---|
| `QUOTE_MISSING` | A stored quote is gone from the page; the note IDs are listed. | Re-read those notes first. |
| `CHANGED` | The page changed and some of its notes have no stored quote. | Re-read every note on that page. |
| `UNAVAILABLE` | The page did not load. | Check by hand; find the new address or retire the notes. |
| `SUPPORTED` | The page changed but every stored quote is still there. | None. |
| `BLOCKED`, `UNSTABLE` | Bot protection, or a page that differs on every fetch. | Check in a real browser. Never flags notes. |

**Sites that need a real browser:** Newport Aquarium (Akamai), AMC and IMAX (Cloudflare), Molly Malone's, Heritage Village, the Cincinnati Symphony (form redirect). The NKU policies page fails TLS under the system Python.

**`grab.py`** extracts the final JSON from a Claude Code sub-agent transcript. Other tools will not need it; have the agent write its JSON to a file.
